Design and build a one-page responsive portfolio website that incorporates Flexbox, CSS Grid, media queries, and animations to create a polished and interactive layout. Use Flexbox to manage alignment and spacing efficiently, and apply CSS Grid to structure at least one section of the page
This project is an enhanced version of the previous Lab 2 portfolio, upgraded using modern CSS techniques. The website contains clean sections including a Header, Hero, About, Skills, Projects, Contact, and Footer. The goal is to create a polished, responsive, and visually appealing layout.
Objectives

Build a responsive one-page portfolio using Flexbox and Grid.

Use media queries for mobile, tablet, and desktop screens.

Apply relative units (rem, %, vw, vh) for scalable spacing & fonts.

Include hover effects, CSS transitions, and animations for interactivity.

Improve layout, spacing, alignment, and visual hierarchy.

Implement keyframe animations in at least one section.
# Features Implemented
1. Header (Flexbox)

Logo + navigation arranged using Flexbox.

Hover effects added to menu links.

 2. Hero Section (Flexbox + Animation)

Text on left, profile image on right.

“Full Stack Developer” animated using CSS keyframes.

3. About Section

Clean text block describing the user.

 4. Skills Section (CSS Grid)

Displayed in 3 columns using Grid.

Skill cards with hover & transform effects.

5. Projects Section (CSS Grid)

Two project cards arranged in Grid layout.

Includes subtle hover animations.

6. Contact Section

Simple form with input fields and a submit button.

Styled using relative units and spacing rules.

7. Footer

Copyright text.
 8. Animations & Transitions

Color-changing heading animation (keyframes).

Smooth hover transitions on buttons, cards, and links.
Responsive Design

The website is mobile-first and adapts to all screen sizes.

#Breakpoints Tested
Device	Width	Behavior
Mobile	≤ 600px	Hero stacks, grids become 1-column, form becomes full width
Tablet	601–900px	Larger text, elements center aligned
Desktop	≥ 900px	Full layout with flex and grid sections
